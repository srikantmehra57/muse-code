Use your own agent

Muse is the default. The app also works with other coding agent CLIs installed on your computer, using your own accounts.

Your own API key

Sign in with a Muse Code subscription or add your own META_API_KEY. It's stored in your system keychain.

Other CLIs

OpenCode and Grok are fully supported. Gemini CLI, Qwen Code and Goose are experimental. Install one, sign in, then click Rescan.

Switch anytime

Change the agent from the composer. Your chat history stays in the thread.
